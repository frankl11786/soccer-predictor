# Match prediction-market readability

This patch changes only `app/styles.css`.

It increases the type size, spacing, and readability of the prediction-market comparison cards on match pages, including:

- outcome labels
- Model / Polymarket / Kalshi / Consensus rows
- Kalshi bid-ask range
- plain-English market explainer
- market metadata and comparison-only note

No model, prediction, market-data, archive, or workflow logic is changed.
